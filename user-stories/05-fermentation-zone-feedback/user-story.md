# See Fermentation Zone Feedback

## Slice
2 — Sourdough with Manual Starter %

## Story
As a sourdough baker, I want to see a red/yellow/green zone indicator for my fermentation window, so that I know if my timing is feasible before I commit.

## Acceptance Criteria
- Zone derived from fermentation window duration, dough temp, and hydration
- Red: < 4h or > 36h (not feasible / over-fermentation risk)
- Yellow: 4-6h or 24-36h (tight / very sour)
- Green: 6-24h (ideal range)
- Zone indicator updates live as inputs change
